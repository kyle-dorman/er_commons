# ER Bench

`er_bench` is the first planned capability in ER Commons. This tracked folder
will own its benchmark contract: task definition, dataset version references,
split policy, evaluation protocol, and small schemas or fixtures.

The benchmark inputs, snapshots, and run outputs belong outside Git under:

```text
/Volumes/x10pro/er_commons/benchmarks/er_bench/
```

Sprint 1 accepted the first benchmark contract in `sprint1.md`. Sprint 2 is
current and implements that contract one bounded task at a time. Each task is
written immediately before its bounded work begins.

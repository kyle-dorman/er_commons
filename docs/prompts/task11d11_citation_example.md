Example 1 — A complete answer with an explanatory basis.
Question: Can the archive restore a deleted file, and what does restoration require?
Example passage EX-A: "A file can be restored if it appears in an available snapshot. The operator must select that snapshot and request restoration. Restoration copies the saved file from the selected snapshot back into the archive."
A complete conclusion is: "The file can be restored if an available snapshot contains it; the operator must select that snapshot and request restoration."
A supporting point cites EX-A and explains that restoration uses the file's saved copy in the selected snapshot. Merely saying "restoration is possible" omits both the condition and the required action. Restating "the file can be restored because restoration is possible" supplies no explanatory basis.

Example 2 — A citation must support the whole claim, including the link between facts.
Example passage EX-B: "In the library catalog, collection 7 is the Atlas Collection and collection 9 is the Harbor Collection."
Example passage EX-C: "Collections 7 and 9 may be borrowed for 14 days. Collection 9 requires a condition review before display."
A point saying "The Harbor Collection may be borrowed for 14 days" cites both EX-B and EX-C: EX-B identifies the collection, and EX-C supplies its borrowing period. Citing EX-B on a different point does not supply that identification here. Alternatively, split the claim into "The Harbor Collection is collection 9" citing EX-B and "Collection 9 may be borrowed for 14 days" citing EX-C.
A point saying "The condition review may change the Harbor Collection's borrowing period" is unsupported even if it cites both passages. The passages establish a borrowing period and a condition for display, but do not connect the review to the borrowing period. Remove that inferred relationship; if relevant to the question, state the two supported facts separately. Keep the distinction between borrowing and display.
